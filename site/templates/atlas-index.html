Every node in the atlas has a page, whether or not anything has been written on it. An empty field is shown as a gap rather than hidden, which is why most of what follows is visibly unfinished.

These nine are not a division of anything. Rule 03 asks whether a set of parts is collectively exhaustive, and that question needs a parent to be exhaustive of. This list has none, so the rule cannot be applied to it. That is an open problem, not an oversight, and it sits above everything below.
